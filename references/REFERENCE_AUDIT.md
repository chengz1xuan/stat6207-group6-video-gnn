## Typography and authors

The previous XeTeX build had undefined `TU/ptm` regular/bold/italic shapes, so the class silently fell back to regular Latin Modern. `T1` font encoding restores embedded Times-family regular, bold and italic Type 1 fonts. The IEEEtran `abstract` environment consequently renders the complete abstract in real bold, with its native bold-italic run-in label.

The four authors now use separate `IEEEauthorblockN` / `IEEEauthorblockA` units, arranged in two rows. Names use IEEE given-name/family-name order (for example, Zixuan CHENG); the exact supplied surname-first forms remain in AUTHORS.json. Each block contains the corresponding supplied identity, the already-stated CUHK affiliation, Hong Kong SAR and the matching supplied email. No unsupplied department, position, membership or ORCID is invented.
